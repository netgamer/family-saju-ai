# Family Saju AI

가족 구성원의 생년월일과 출생시간을 기반으로 만세력을 계산하고, 가족 관계에 맞는 대화 방법을 AI로 안내하는 서비스입니다.

## 목표

1. 가족 구성원 프로필 등록
2. 출생정보 기반 만세력 산출 및 저장
3. 두 가족 구성원의 관계/상황 선택
4. 저장된 사주 데이터를 바탕으로 관계 분석
5. 실제 대화에 사용할 수 있는 구체적인 말투와 예시 제공

## 개발 방향

- 만세력 계산 로직과 AI 해석 로직을 분리합니다.
- 사주 원국 등 계산 결과를 DB에 구조화하여 저장합니다.
- AI에는 필요한 관계 정보와 계산된 사주 데이터만 전달합니다.
- 사주 해석은 오락·자기성찰 목적의 참고 정보로 제공하며 중요한 의사결정의 근거로 사용하지 않습니다.
